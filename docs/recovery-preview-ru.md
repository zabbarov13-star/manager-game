# Менеджер — Назад в прошлое · предварительная версия

Утверждённый интерфейс взят из a62f934. Ветка подготовки обновляет только визуальное движение и звук броска, добавляет оболочки и упаковку. Игра на действующем тестовом VPS обновляется отдельно. Точные данные сборки находятся в VERSION.json и SHA256SUMS.txt.

## Скачать и установить

1. Откройте [выпуски на GitHub](https://github.com/zabbarov13-star/manager-game/releases).
2. Найдите предварительную версию **v0.19.1-preview.2**. Откройте **Assets**.
3. Скачайте файл для своего устройства. Для резервной копии сохраните **Manager-Release-Backup.zip** на отдельный носитель и запишите SHA-256 из списка файлов выпуска.

| Устройство | Как запустить |
| --- | --- |
| Android | Скачайте Manager-Android-preview.apk, откройте его и разрешите установку этому источнику, если Android запросит разрешение. Предварительный APK имеет отдельный идентификатор приложения. Для обновления поверх предыдущего APK нужны тот же ключ и больший versionCode. Публичная тестовая сборка использует ключ CI, поэтому перед заменой экспортируйте сохранения в игре, если функция доступна в текущем режиме. |
| Android PWA | Откройте игру в Chrome по HTTPS. В меню браузера выберите «Установить приложение» или «Добавить на главный экран». |
| iPhone/iPad PWA | Откройте игру в Safari по HTTPS. Нажмите «Поделиться» → «На экран Домой». Первый запуск выполните с подключением к сети. |
| Windows | Запустите Manager-win-x64.exe. Для портативного варианта распакуйте Manager-win-x64.zip в папку и запустите Manager.exe. Сборка предназначена для x64 и не имеет подписи Authenticode. |
| Mac | Выберите DMG для Apple Silicon (arm64) или Intel (x64). Откройте образ и перетащите приложение в «Программы». Предварительный пакет не подписан Developer ID и не нотарифицирован, поэтому доступность запуска зависит от политики Gatekeeper. Используйте веб-версию, если система блокирует приложение. |
| iPhone/iPad приложение | В исходниках есть Xcode-проект. Физическая установка требует подписи. Для TestFlight нужны Apple Developer Program, приложение в App Store Connect, подходящий Bundle ID и архив с подписью Apple Distribution. Для прямого тестирования нужен provisioning profile с разрешённым устройством. |

Приложения, архивы и подписи, которых нет в **Assets**, ещё не доступны для скачивания. AAB с пометкой unsigned предназначен для последующей подписи ключом загрузки, его нельзя установить напрямую. Android и настольные оболочки используют встроенный клиент, а комнаты открывают на существующем тестовом сервере. Нативная оболочка iOS хранит локальную игру во встроенном клиенте и открывает актуальную серверную игру в отдельном окне. Звук онлайн-броска в этом окне зависит от версии сервера.

Для PWA нужен HTTPS и корректный MIME-тип манифеста. [Текущий адрес OnlineVDS](https://95-181-169-84.sslip.io/) отдаёт утверждённую ранее сборку. Для предварительной PWA разместите Manager-Web.zip на отдельном тестовом HTTPS-адресе вместе с сервером комнат или настройте маршрутизацию /api/rooms на тот же origin. Manager-Standalone.html открывается как файл для игры за одним устройством. Серверные комнаты и установка PWA из file:// недоступны.

## Как передать проект разработчику

Передайте Manager-Source.zip, VERSION.json и SHA256SUMS.txt или ссылку на тег. Клиент, изображения и звук находятся в index.html. Часть ресурсов встроена в HTML. online/generate.cjs собирает онлайн-клиент и серверный движок. online/server.cjs поднимает комнаты, SQLite и статические файлы. packaging содержит общую подготовку ресурсов, исходники Android, iOS и Electron, настройки сборки и тесты. Исходники не содержат данные комнат и ключи подписи.

### Воспроизводимая сборка

- Общий клиент: Node.js 24.22.1, затем `node online/generate.cjs`.
- Android: JDK 17, SDK 35 и Build Tools 35.0.0, Gradle 8.9. Выполните `python3 packaging/stage-native.py android`, затем `gradle -p packaging/android :app:assembleDebug :app:bundleRelease`.
- Windows и Mac: выполните `python3 packaging/stage-native.py desktop`, затем `npm ci` в packaging/desktop. Для Windows запустите `npx electron-builder --win nsis zip --x64`, для Mac — `npx electron-builder --mac dmg --arm64 --x64`.
- iOS: выполните `python3 packaging/stage-native.py ios`, откройте packaging/ios/Manager.xcodeproj в Xcode, выберите свою команду подписи и зарегистрированный Bundle ID. Для распространения Mac вне App Store потребуется сертификат Developer ID Application, hardened runtime, отправка на нотарификацию и прикрепление результата.
- Контроль: `node --test packaging/test-dice.cjs online/construction.test.cjs online/public.test.cjs`. Пошаговый CI находится в .github/workflows/manager-preview.yml.

## Восстановление и перенос сервера

1. Подготовьте отдельный Debian 12 VPS с DNS-записью на его адрес и доступными TCP-портами 80/443. Сохраните доступ к SSH и проверьте его фактический порт. Установщик настраивает Caddy и правила nftables, поэтому впервые запускайте его на выделенном VPS. Архив содержит Node.js для Linux x64 и arm64, закреплённый SHA-256. Для системных пакетов Debian нужен доступ к репозиториям.
2. Распакуйте Manager-Server.zip. Из корня распакованной папки администратор запускает `sudo bash online/vps/install.sh game.example.org 22`, подставив реальное имя и SSH-порт. Проверьте `/health` по HTTPS. Схема SQLite создаётся при запуске в online/server.cjs. Для существующего формата таблиц используется обратно совместимое создание при отсутствии.
3. Старый сервер: запустите `sudo systemctl start manager-backup.service`. Скопируйте последнюю проверенную копию из /var/backups/manager-online по защищённому каналу. Она содержит реальные комнаты, храните отдельно от публичных архивов.
4. Новый сервер: остановите manager-online, сохраните текущую базу и её sidecar-файлы, проверьте копию через `sqlite3 COPY 'PRAGMA quick_check;'`. Перенесите её как /var/lib/manager-online/rooms.sqlite с владельцем manager-online, правами 0600 и без старых WAL/SHM от другой базы. Запустите службу и проверьте прежнюю комнату.
5. При переносе адреса сохраните прежнее DNS-имя, если это возможно. Для нативных предварительных пакетов изменение хоста требует пересборки конфигурации оболочек. Локальные сохранения на телефоне или ПК принадлежат устройству и не переносятся с SQLite.
6. Перед обновлением сделайте копию базы, проверьте совместимость на отдельном сервере и сохраните ссылку на предыдущий релиз в /opt/manager-online/releases. Для смены только приложения используйте проверяемый пакет и процедуру обновления из online/vps/README-RU.md. Для отката переключите /opt/manager-online/current на предыдущий релиз и перезапустите службу. Восстановление базы выполняйте отдельно, только при необходимости, после сохранения текущего состояния.
