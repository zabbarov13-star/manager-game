# Реальные Telegram-клиенты: компактная приёмка

Статус сценария: **NOT RUN**. Подготовка сценария и наличие клиента не являются PASS игры.

## Перед началом

Нужен разрешённый изолированный HTTPS-стенд с исполняемым кодом `a3279b0a1f1b697f8662a2b911eadd9dc9b92425` (или доказанно идентичными исходниками), тестовым ботом и отдельными тестовыми данными. Сопоставление URL, артефакта и SHA подтвердить манифестом стенда. Если версия/изоляция не подтверждены — **BLOCKED**, рабочий сервер для этого прогона не использовать. В этой работе стенд не развёртывался и настройки бота не менялись.

Использовать настоящий Telegram Desktop, Telegram Web с настоящей авторизованной сессией и Telegram на физических Android/iPhone. Browser viewport, Android Emulator, iOS Simulator и подставной WebApp SDK отмечаются отдельно и не заполняют эти строки PASS.

Нужны два разрешённых тестовых аккаунта; для сравнения прав — обычный игрок и владелец. Авторизацию пользователь выполняет самостоятельно. initData, сессии, числовые ID, токены и данные чужих чатов в отчёт не переносить.

## Один круг на каждом клиенте

| № | Действия | Ожидаемый результат |
|---|---|---|
| 1 | Открыть Mini App из тестового бота, затем закрыть и открыть повторно | Проверенный стенд, главное меню, корректный русский интерфейс; вход без зависания |
| 2 | Открыть настройки, правила, магазин и вернуться | Доступные кнопки, читаемый текст, сохранённые настройки; нет наложений и обрезания safe areas |
| 3 | Обычным аккаунтом рассмотреть 12 премиальных героев, портреты и анимации; вернуться к выбору | Изображения и реакции видимы; предпросмотр не выдаёт игровое право |
| 4 | Сравнить обычный аккаунт и владельца | Закрытый контент остаётся закрытым у обычного; владельцу доступна косметика без предложения оплатить уже доступное |
| 5 | Начать тестовую партию, бросить, купить игровое владение; проверить карточку и «Отдых» | По одному действию на нажатие; допустимые фазы; правильные вкладки; «Отдых» открывает обзор без изменения денег |
| 6 | Масштабировать поле, вручную сдвинуть камеру, дождаться автоматического движения | Читаемые клетки и карточки, устойчивые позиции фишек, камера уважает ручное управление |
| 7 | Продолжить после закрытия Mini App и перезапуска Telegram | Тестовая партия, выбор и доступные права восстановлены; нет повторного исполнения прежнего броска/покупки |
| 8 | Создать сетевую тестовую комнату и подключить второй реальный клиент; выполнить по ходу каждым | Совпадают поле, деньги, собственность и персонажи; кубики принадлежат бросающему; в существующем режиме PeerJS используется внешний сигналинг |
| 9 | Отправить сообщение в чат тестовой комнаты, открыть/закрыть клавиатуру, сменить размер окна/ориентацию | У другого участника появляется непрочитанное уведомление; ввод не перекрыт; после чтения индикатор снимается |
| 10 | Свернуть Telegram и вернуться; на физическом телефоне сменить Wi-Fi/мобильную сеть; восстановить соединение хоста | Анимации приостановлены в фоне; состояние согласовано после возврата; нет повторных ходов и проигрывания старых событий |
| 11 | Включить reduced motion системными средствами, проверить движение и результат партии | Нет непрерывных эффектов; игра и результаты работают; победа/поражение корректно показаны |

Шаги, требующие двух устройств/аккаунтов, не подменять двумя контекстами одного браузера. Создание/использование тестовых комнат допускается только после подтверждения изоляции стенда. Не создавать счета, не подтверждать платежи/возвраты, не запускать AdsGram и не изменять реальные права или базы. Финансовые и рекламные сценарии требуют отдельной разрешённой приёмки.

## Запись результата

Для каждого клиента записать: платформа, фактическая версия Telegram/ОС, физическое устройство либо Desktop/Web, SHA/артефакт стенда, дата, номер шага, PASS/FAIL/BLOCKED и краткое обезличенное наблюдение. Для шага 3 отмечать просмотренных героев и состояния; непроверенные сочетания не считать пройденными. Скриншот при необходимости ограничивать Mini App и обезличивать.

| Клиент | Фактический игровой прогон | Причина |
|---|---|---|
| Telegram Desktop / Windows | BLOCKED / NOT RUN | Окно и UIA доступны; нет подтверждённого стенда проверенного SHA |
| Telegram Web | BLOCKED / NOT RUN | Не проверены реальная авторизованная сессия и версия стенда |
| Telegram / физический Android | BLOCKED / NOT RUN | Физическое устройство не предоставлено для этого прогона |
| Telegram / физический iPhone | BLOCKED / NOT RUN | Физическое устройство не предоставлено для этого прогона |

## Автоматизация

Подтверждено на Windows: установленный Telegram Desktop запускается, предоставляет целевое окно и дерево доступности UIA через `computer-use`. Данные чатов и авторизации не экспортировались. После предоставления проверенного стенда можно автоматизировать навигацию и обезличенную фиксацию результатов в настоящем клиенте. Наличие UIA не гарантирует доступность каждого элемента встроенного WebView; это проверяется на стенде.

В текущем окружении `adb` не найден в PATH и проверенных стандартных SDK-путях; доступ к физическому Android этим не подтверждён. Управления физическим iPhone нет. Telegram Web может проверяться через браузерный интерфейс после предоставления настоящей сессии. Существующие Playwright fixtures и Simulator подтверждают свой автоматический контур; реальную Telegram-авторизацию, сетевое переключение телефона и физическую приёмку они не заменяют.
