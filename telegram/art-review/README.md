# Премиальная коллекция: переработка графики

Ветка `art/premium-characters-v2` основана на `feature/telegram-mini-app` (`2861ec8`). В коллекции по-прежнему ровно 12 премиальных персонажей. Новые персонажи не добавлялись.

| Направление | Персонажи |
|---|---|
| Объёмный стилизованный 3D-рендер | Мира, Тимур, Луна, Феликс |
| Рисованная 2D-мультипликация | Ася, Оскар, Белла, Марсель |
| Детализированное аниме | Акира, Хана, Рэн, Юки |

Все изображения оригинальные. Для каждого героя созданы основной образ, отдельный крупный портрет и лист из четырёх эмоциональных поз с сохранением лица, костюма и палитры. Вместе с основным образом это пять состояний: ожидание, радость, разочарование, победа и поражение.

## Посмотреть результат

- [Галерея «До / После»](index.html): сравнение портретов и фигурок каждого из 12 персонажей, затем все пять новых состояний. Открывается локально после загрузки репозитория; GitHub показывает исходный HTML.
- [Общий лист сравнения](before-after.png).
- [Сравнение портретов](before-after-portraits.png).
- `screenshots/`: реальные снимки игрового интерфейса из автоматической проверки, по три снимка каждого персонажа на мобильном и настольном экранах — портрет, победа и поле.
- `browser-results.json`: результаты прохода по всем 12 персонажам на двух размерах экрана.
- `asset-report.json`: размеры исходных изображений, контрольные суммы и объём экспортированных ресурсов.

`before/` содержит исходные WebP из базовой ветки. В галерее используются настоящие старые и новые игровые ресурсы при одинаковых размерах отображения; это не отдельные рекламные макеты.

В Git сохранены облегчённые WebP-копии 72 снимков без изменения размеров. Исходные PNG остаются локально и заново создаются браузерным тестом. Для экспорта копий используется `node telegram/art-review/export-screenshots.cjs` с пакетом `sharp`.

## Предпросмотр и анимация

Любую заблокированную премиальную карточку можно открыть бесплатно. В ней доступны крупный портрет, вид в полный рост, увеличение, биография, характеристики и все пять состояний. Переключение эмоций заменяет растровую позу и выражение лица. Ожидание дополняется лёгким дыханием; победа — движением и расходящимися золотыми частицами. Настройка уменьшения движения отключает CSS-анимацию, оставляя изображения эмоций доступными.

Настоящие трёхмерные модели и дополнительные ракурсы не создавались. Поэтому интерфейс не имитирует поворот плоской картинки: предлагаются честные режимы «Портрет» и «В полный рост». Анимация реализована отдельными ключевыми позами и CSS-движением; это не покадровая или скелетная анимация.

Просмотр не обращается к выдаче доступа, не запускает рекламу и не создаёт счёт. Кнопки покупки и рекламного доступа используют прежние обработчики и цены. На поле эмоция меняется только в слое отображения премиальной фигурки. Игровой движок, значения кубиков, счёт, баланс, платёжная и рекламная логика не изменены.

## Ресурсы и воспроизводимость

- `../assets/<id>.webp`: основная игровая фигурка, прозрачный холст 384×576.
- `../assets/<id>-portrait.webp`: облегчённый крупный план для карточки 512×512.
- `../assets/premium-v2/<id>-portrait-large.webp`: отдельный портрет в исходном высоком разрешении, без искусственного увеличения.
- `../assets/premium-v2/<id>-{joy,failure,win,loss}.webp`: прозрачные эмоциональные позы 384×576.
- `../assets/premium-v2/generation.json`: точные промпты встроенного `image_gen` и художественное задание для каждого персонажа.

`prepare.cjs` экспортирует уже сгенерированные изображения: сохраняет альфа-канал, делит лист поз на четыре ячейки, подрезает прозрачные поля, масштабирует и сжимает WebP. Он не рисует персонажей и не подменяет их векторными заготовками. Для экспорта нужен пакет `sharp`; пути к исходным PNG передаются через приватный JSON и в Git не попадают. Необязательный третий аргумент выбирает одного персонажа для повторного экспорта.

```sh
node telegram/art-review/prepare.cjs path/to/private-inputs.json
node telegram/art-review/generate.cjs --png
node telegram/build.cjs
node --test telegram/tests/*.test.cjs tests/p2p-routing-baseline.cjs
node --require ./telegram/tests/release-preload.cjs --test packaging/test-dice.cjs online/construction.test.cjs online/public.test.cjs
node telegram/tests/browser-smoke.cjs
node telegram/tests/premium-browser.cjs
```

Для браузерных сценариев требуется Playwright 1.62.1 и Chromium. Можно указать `QA_CHROME` для установленного Chrome. Проверка запускает настоящий клиент и сервер с подписанным тестовым `initData`, но имитирует Telegram-host. Настоящие платежи и рекламные просмотры не совершаются. Синтетические покупки для осмотра поля добавляются только в изолированную базу в памяти и только после проверки заблокированного предпросмотра.

Бесплатные персонажи и их исходная графика, данные всех 18 персонажей, цены 10/25 Stars, рекламный доступ на 24 часа и общий лимит трёх просмотров сохранены. Внешние ограничения подключения AdsGram и Stars из основной ветки этим визуальным обновлением не меняются.
