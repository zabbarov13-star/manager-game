## Не проверено и не завершено

- Реальный Telegram initData на Android/iOS/Desktop/Web; безопасные области и сворачивание на физических устройствах.
- Настоящая реклама AdsGram. Нет Block ID и проверяемого источника уникальных событий; доверенный адаптер провайдера не реализован. Реклама отключена.
- Настоящие Stars, проверка в тестовой среде Telegram, реальный возврат. Серверная реализация проверена синтетическими webhook-событиями, внешние Bot API вызовы заменены тестовыми ответами.
- Реальная межплатформенная PeerJS-партия и восстановление соединения в Telegram. Тесты маршрутизации не доказывают доступность Render и WebRTC у всех игроков.
- Премиальный образ не синхронизируется с другими клиентами: используется локальная оболочка исходного сетевого ID. Требует дальнейшего расширения отображаемых метаданных с обратной совместимостью.
- Истечение временного персонажа во время локальной партии поддержано; полный цикл истечения и повторного входа в сетевую партию требует дополнительной проверки.
- Production HTTPS, привязка бота и Docker-сборка пока не подтверждены внешним запуском. Dockerfile подготовлен; локальный Docker не запускался.

Исходные HTML, `online/`, нативные сборки, ветки, теги и отдельный репозиторий PeerJS-сервера не изменялись. Полные критерии готовности из ТЗ ещё не достигнуты; результат является проверенной основой реализации, требующей указанных интеграций и приёмочных проверок.
