# Менеджер — Назад в прошлое · мобильный выпуск 0.19.0

Оригинальная рабочая основа: game-0.18.3.html. Правила/экономика/P2P-протокол сохранены. Изменения: мобильные оболочки, встроенные офлайн-ресурсы, компактное меню соединения и автоматизация сборки/проверок.

Android: реальный подписанный Manager-Android.apk для личной установки. Отдельный package ID ru.manager.backtothepast.personal позволяет сохранить прежнюю официальную линию подписи. Не теряйте приватный резервный комплект нового личного ключа: он нужен для обновлений этой сборки.

iPhone/iPad: один проект WKWebView, поддерживающий обе группы устройств. Офлайн-игра встроена. Онлайн открывается внутри приложения по действующему HTTPS Pages-адресу, с той же игровой логикой/Render PeerServer, без адресной строки. Применяется компактная мобильная панель соединения. При возврате к локальной игре сетевое соединение закрывается с предупреждением. Без сети локальная игра остаётся доступной.

Все необходимые игровые графика, музыка, шрифты и сценарии находятся в исходном HTML и подготовленных мобильных assets. Для запуска APK интернет не требуется. Для пересборки нужны инструменты разработчика; SDK/JDK/Xcode не являются игровыми ресурсами и устанавливаются отдельно.

Восстановление: распакуйте полный архив, выполните `python3 mobile/tools/build-client.py`. Сборка APK описана в android/RELEASE.md. Облачная сборка и безопасные секреты — docs/CI-SECRETS-RU.md. Не нужно сохранять этот чат: исходники, история Git и инструкции включены в комплект. Ключи подписи передаются отдельно и не входят в публичные исходники.

Состояние фактических проверок/ограничения — QA-REPORT-RU.md. Установка, подпись, компиляция и физический тест не считаются одним и тем же результатом.
