# Android · постоянная подпись и обновления с 0.17

Приложение: `ru.manager.backtothepast`, первая версия новой цепочки: `0.17.0`, versionCode `17`. Отпечаток сертификата, alias и минимальная версия зафиксированы в `release.json`. Это открытые сведения; закрытого ключа в исходниках нет.

## Первый переход с версии 13

Старый ключ версии 13 недоступен. По согласованию владельца партии переносить не требуется. Удалите старое приложение один раз и установите manager-android-0.17.apk. Подпись новой версии другая. После этого не удаляйте приложение ради обычных обновлений: следующие APK должны подписываться новым постоянным ключом, сохранять applicationId и повышать versionCode.

## Резервная копия подписи

Владельцу отдельно передаётся `manager-android-signing-backup.zip`: manager-release.p12, password.txt, публичные certificate.der/identity.json и инструкция. Это ЗАКРЫТЫЙ архив, его нельзя публиковать, коммитить или прикладывать к публичным релизам. PKCS12 защищён случайным паролем; пароль находится в приватной резервной копии. Сохраните архив минимум в двух независимых защищённых местах. Не рассчитывайте на сохранность временной рабочей среды разработчика. Для будущей сборки передайте этот архив доверенному сборщику приватно; не создавайте новый ключ.

`build.py` никогда не создаёт ключ сам. Если ключ не найден или сертификат отличается от release.json, сборка останавливается. Одноразовое создание новой identity вынесено в отдельный create-signing-key.py; повторное создание в занятой папке запрещено. Никогда не запускайте этот скрипт для обычного обновления.

## Воспроизводимая подготовка инструментов

Linux, Python3, полный JDK21 (модуль jdk.compiler). При необходимости задайте JAVA_HOME. Загрузки берутся с dl.google.com; SHA-256 и размеры в toolchain-lock.json. Скрипт ничего не подписывает и не работает с секретами:

```
python3 android/setup-sdk.py --directory /absolute/path/to/android-sdk
python3 native/build.py
```

## Сборка

Распакуйте приватную подпись вне репозитория. Пароль не помещается в командную строку: передаётся путь к файлу с правами 600.

```
python3 android/build.py --sdk /absolute/path/to/android-sdk --html /absolute/path/to/build/native/android/game.html --output /absolute/path/to/manager.apk --keystore /private/path/manager-release.p12 --password-file /private/path/password.txt
```

Для следующего выпуска измените versionCode/versionName в AndroidManifest.xml и release.json, обновите ресурсы через native/build.py и передайте `--previous-apk /path/to/previous-release.apk`. Проверяется подпись предыдущей APK, неизменный applicationId и строго больший versionCode. Не используйте тестовую update-probe APK как публичный релиз.

Сборщик очищает старые классы/DEX, проверяет конечную подпись, package/version, zipalign с размером страницы 16 КБ, CRC и точное содержимое встроенной игры. Рядом с APK создаётся JSON с SHA-256, сертификатом и результатами проверки. Дополнительно APK подписывается схемами, выбранными apksigner для minSdk26. Перед публикацией на магазине отдельно проверяются его текущие требования к target SDK, метаданным и privacy. Этот APK предназначен для прямой установки, регистрация Google Play не выполнена.

## Онлайн и совместимость

Офлайн-страница и её ресурсы находятся внутри APK. INTERNET-разрешение отсутствует. Выбор онлайн открывает форму HTTPS-адреса; только явная кнопка запускает серверный клиент в системном браузере. Адрес не зашит в APK, chatgpt.site не используется. Независимый сервер ещё нужно разместить; инструкция deploy/README.md. На сервере размещается полный текущий клиент и API вместе, что исключает смешение встроенного офлайн-клиента со случайной версией API. Локальная партия остаётся в приложении, сетевые комнаты — на сервере. Открытие браузера не является переносом локальной партии в онлайн.

При будущем переходе к сетевому экрану внутри приложения сохраняйте раздельные хранилища, явное включение сети, HTTPS, проверку API/правил перед входом, токены только в защищённом хранилище и обратную совместимость сохранений. Установка новой APK не должна зависеть от работающего сервера. Автообновление из неизвестных источников не реализовано.

## Выпуск и испытания

Для каждого релиза: полные Node-тесты; сборка; apksigner/zipalign; установка на чистый Android; запуск в авиарежиме до первого старта; партия с людьми/ботами; события/музыка/поворот; экспорт/импорт; установка поверх предыдущей версии с сохранением партии; затем реальные онлайн-партии на разных устройствах и сетях. Текущая среда проверяет компиляцию/подпись и цепочку метаданных обновления, но не заменяет физическую установку и испытания.
