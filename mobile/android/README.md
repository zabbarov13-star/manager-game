# Android 0.19.0 — подписанная личная сборка

Собирается из исходной рабочей HTML-игры 0.18.3, без изменения правил, поля, экономики и P2P-протокола. APK: Manager-Android.apk. Package ID: ru.manager.backtothepast.personal, versionCode20. Минимум Android8.0/API26, актуальный Android System WebView/Chrome обязателен.

Для личной установки создан отдельный ключ по явному разрешению владельца. Его сертификат закреплён в release.json. Ключ и пароль передаются отдельным приватным резервным архивом, не хранятся в публичном репозитории. Сборщик никогда не генерирует ключ и отказывается подписывать другим сертификатом. Этот APK устанавливается рядом с прежней официальной ru.manager.backtothepast и не заменяет её данные/подпись.

Все ресурсы встроены. Офлайн запускается без сети. Онлайн — внутри WebView, на HTTPS-origin appassets.androidplatform.net, с тем же PeerServer Render. Интернет включается игровым кодом только при явном открытии онлайн-режима. Нет адресной строки и перехода в браузер. Камера/микрофон не требуются для игровых DataChannel-соединений.

Установка: скачайте APK на Android, разрешите установку из используемого файлового менеджера/браузера, откройте файл. Отключать Play Protect не требуется. При предупреждении/ошибке установки сохраните её текст. Физическое устройство, эмулятор и криптографическая проверка — разные проверки; актуальный результат указан в QA-REPORT-RU.md.

Сборка для разработчика: mobile/tools/build-client.py, затем setup-sdk.py и build.py с защищённым ключом. Для автоматических обновлений используйте тот же личный ключ и увеличивайте versionCode. Для официальной линии требуется прежний ключ владельца и отдельный правильный release-профиль; owner-release-reference.json содержит только публичную справку о той подписи.
