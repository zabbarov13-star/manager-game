# Android · автономная версия 0.17.0

APK собрана с постоянной новой подписью. Android 8.0/API26 и новее; нужен исправный системный WebView. Ресурсы, музыка, боты и локальная игра встроены, интернет для запуска не нужен. В APK нет разрешения INTERNET. Онлайн открывает выбранный независимый HTTPS-сервер в системном браузере только по явному подключению. Публичный сервер пока не развёрнут.

Первый переход с версии 13: удалить старую APK (подпись другая), затем установить новую. Владелец подтвердил отсутствие нужных партий. Со следующих версий — установка поверх без удаления данных, с тем же ключом и более высоким versionCode.

Постоянный ключ и пароль передаются владельцу отдельным приватным резервным архивом. Их нет в исходниках. Сборка не генерирует ключ автоматически и отказывается использовать сертификат, отличный от android/release.json.

Полная инструкция: [RELEASE.md](RELEASE.md). Компиляция, подпись и структура проверены; установка на физическом телефоне и реальные сети ещё не проверены. При ошибке установки не отключайте Play Protect, сообщите точный текст ошибки.

## Исходники P2P0.18

Параметры будущей сборки подготовлены с versionCode18 и прежним сертификатом0.17. APK0.18 пока не подписана: приватный архив ключа не смонтирован в этой среде. Новая подпись не создаётся. Для выпуска используйте тот же manager-release.p12 и --previous-apk APK0.17. P2P-браузерная сборка может быть размещена статически на HTTPS, без игрового сервера/VPS; Android открывает её по настроенному адресу в системном браузере. Самостоятельный локальный режим остаётся встроенным и изолированным от сети.
