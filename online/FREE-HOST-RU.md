# Проверка alwaysdata Free и бесплатный домашний вариант

Решение для личного некоммерческого теста. Площадка указывает 0 €/месяц, SSD 1 ГБ, 256 МБ RAM, ¼ CPU, три дня резервных копий и адрес alwaysdata.net. Node.js 24 поддерживается. При отсутствии карты аккаунт остаётся в ограниченном режиме с более строгой обработкой HTTP. Конкретные лимиты запросов и исходящего трафика, поведение после простоя и срок запуска этого приложения ещё требуется проверить на реальном аккаунте. Тариф не следует считать гарантией круглосуточной работы или доступности из любой сети.

## Проверка маршрута

7 ноября 2026 г. три публичных узла Globalping из РФ получили HTTPS 200 от demo.alwaysdata.net. Узлы находились в сетях Timeweb (Москва), Selectel (Санкт-Петербург) и Yandex.Cloud (Москва). [Результаты замера](https://api.globalping.io/v1/measurements/2GU0Y2L2l0YodVYHO00021Sec). Панель admin.alwaysdata.com вернула HTTPS 302 с трёх российских узлов. [Замер панели](https://api.globalping.io/v1/measurements/2bi3ZREgsjV682iUy00021Sea).

Проверены общедоступные адреса провайдера. Для приёмки нужен отдельный адрес игры, успешный запрос /health и полный сценарий комнаты на телефоне с недоступным Render. Ни один тест этого документа не измерял доступность мобильных операторов.

## Почему alwaysdata не выбран для новой регистрации

На открытой форме регистрации Free появилось обязательное подтверждение дебетовой или кредитной карты. Описание ограниченного режима для аккаунтов без карты не отменяет эту проверку при регистрации. На таком условии новую учётную запись не создаём.

Автоматизация alwaysdata в ветке отключена. Она может использоваться только при наличии уже действующего отдельного аккаунта Free, который не требует карты для выбранного запуска.

## Бесплатный домашний вариант

Node и база работают на постоянно включённом компьютере владельца. Тестовый пакет содержит launcher для Windows и сервер с SQLite. Launcher привязывает приложение к 127.0.0.1:8080. База лежит в отдельном каталоге manager-online/data в домашней папке пользователя. Переустановка тестового клиента не изменяет её.

Администратор подключает отдельный HTTPS-адрес к loopback-порту 8080. Варианты — HTTPS-прокси с уже доступным публичным адресом владельца или Tailscale Funnel, если условия сервиса допускают использование и фактическая доступность подтверждена. Funnel публикует отдельный HTTPS-адрес для игроков, а Tailscale требуется только на хосте. У него есть ограничения пропускной способности. Сначала проверяются условия регистрации и региональный доступ, затем российские узлы и телефон, где недоступен Render.

Если компьютер выключен, спит или потерял связь, онлайн останавливается до его возвращения. Подтверждённые партии остаются в SQLite. Публичный тест должен быть отделён от GitHub Pages 0.19.0. Удалённый доступ к компьютеру владельца и публикацию адреса настраивает администратор с разрешения владельца.
