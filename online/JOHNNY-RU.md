# HelioHost Johnny · отдельная тестовая игра

Johnny предлагает бесплатные места с ограниченной регистрацией. В документации указаны Node.js 22, Plesk и SQLite. Точный патч Node.js и конфигурацию Passenger необходимо проверить в выданном аккаунте. Нужен Node.js 22.13 или новее, где встроенный node:sqlite загружается без флага. Пакет не требует npm-зависимостей. Отдельный диск или VPS приобретать не нужно.

[Регистрация Johnny Free](https://heliohost.org/signup/reserve/?server=johnny) при проверке вернула сообщение о заполненной квоте. У HelioHost указаны два окна регистрации, в полночь и полдень UTC. В Самаре это 04:00 и 16:00. Чтобы аккаунт оставался активным, владелец должен входить в панель минимум раз в месяц. Превышение лимитов нагрузки может привести к приостановке аккаунта. Тестовая сборка опрашивает комнату раз в 3 секунды вместо 1,8 секунды и приостанавливает опрос в фоне.

## Для владельца

1. Откройте регистрацию Johnny Free в одно из окон и укажите свой адрес почты. Выберите бесплатный план Johnny и домен helioho.st, если площадка предложит этот выбор.
2. Подтвердите регистрацию письмом. Сообщите в чате только факт активации и публичный адрес, выданный площадкой. Пароли, коды входа и ключи не отправляйте.

## Для развёртывания

Артефакт manager-johnny.zip из Actions распаковывается в отдельный application root. В Plesk установить document root на каталог public внутри него, а startup file на johnny-start.cjs. Включить Node.js 22.13+ и HTTPS с действующим сертификатом. Passenger перехватывает единственный вызов listen. SQLite создаётся в manager-online-data/rooms.sqlite в домашнем каталоге аккаунта, за пределами web root и каталога обновления. Для SQLite выбран rollback journal, чтобы рабочие процессы использовали один файл и согласованные транзакции. Новые комнаты используют только HTTPS этого сайта.

После развёртывания проверить /health, Node.js и фактическую возможность записи SQLite. Создать комнату, войти по ссылке с отдельного устройства, проверить игровые ходы и повтор после обрыва. Перезапустить приложение в панели и проверить чтение той же комнаты. Отдельно проверить HTTPS тестового домена из России и с телефона, на котором недоступен Render. Тест на локальных процессах не заменяет проверку Plesk и мобильных сетей.
